WDD 131 - Unit 03 Milestone: Build a Blog Part 1

Place this entire 'blog' folder in the root of your existing 'wdd131' repository.

Site URL after committing and pushing to GitHub Pages:
https://bug542.github.io/wdd131/blog/

Files:
- index.html: semantic HTML and one static book review
- styles.css: CSS Grid, desktop and mobile layout
- blog.js: a small working search control and dynamic footer year

To publish from the repository root:
git add blog
git commit -m "Complete blog part 1"
git push origin main

Check the deployed URL after a few minutes. Run Lighthouse and WAVE accessibility checks on the published site.
